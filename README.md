# Rightway Parking Skill

An AI skill that enables conversational agents to search, compare, and hand off bookings for off-airport, cruise-port, and event parking via [RightwayParking.com](https://rightwayparking.com).

## Features
- **Real-Time Search:** Airport, cruise port, and venue parking lookup.
- **Stay-Specific Quotes:** Automated total cost calculations with promo code handling.
- **Deep-Linked Booking:** Direct pre-populated reservation links for instant checkout.

## Installation & Setup

### Option 1: Gemini CLI / Agent Environment
